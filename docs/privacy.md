# 安能助手隐私权政策

最后更新：2026-09-16

安能助手是浏览器侧栏智能助手。本政策说明扩展在提供问答功能时会处理哪些信息。

## 收集的信息

为了基于当前页面回答问题，扩展会在你主动提问或使用划词/右键功能时读取：

- 当前标签页的标题和网址
- 你选中的文字、图片、链接，或当前页面的可读内容
- 你主动上传或选中的图片、PDF 文本，以及语音输入转写结果
- 你在侧栏中输入的对话内容

扩展不会收集健康、财务或身份验证信息，也不会记录鼠标轨迹或击键。

## 如何使用

上述信息仅用于完成你发起的问答、语音转写、识图或 PDF 提取。对话请求通过本机 Native Messaging Host 发送到公司模型服务。会话和设置保存在本机。

## 不会做什么

- 不会向第三方出售用户数据
- 不会把用户数据用于与侧栏问答无关的目的
- 不会用于信用评估或贷款
